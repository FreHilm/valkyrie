## Goal

Port `GameMenu.cs`: the in-quest menu offering undo, save and a return to the
main menu.

## Acceptance Criteria

- [ ] A menu reachable during play without disturbing the board behind it
- [ ] Undo restores the previous state from the undo stack
- [ ] Save writes the current quest to a slot
- [ ] Returning to the main menu tears the session down and asks first, since an unsaved quest is lost
- [ ] The editor entry is omitted until T-019 lands

## Notes

yet.
