## Goal

Drive a scenario from the quest list to its end screen automatically, so the
milestone T-018 claimed — a published community scenario playable start to
finish — is checked by something rather than asserted.

## Acceptance Criteria

- [ ] A headless run plays one published scenario from selection to the end-of-quest screen
- [ ] It fails on a console error, an uncaught exception, or a state it cannot advance out of
- [ ] It distinguishes "the quest is waiting for the player" from "the quest is stuck"
- [ ] Runs in CI within a sensible time budget
- [ ] A second scenario added once the first is green

## Notes

Depends on T-024: no scenario can currently reach its end, so this cannot pass
until puzzles are wired.

There is a working starting point in this session's scratchpad — a CDP harness
that presses whatever is actionable, sweeps the canvas for board pieces, wounds
and defeats monsters, and reports where it stops. On Exotic Material it got
through the intro, party setup, two tiles explored, two Cultists killed and a
door unlocked before losing the thread. Its main weakness is that it cannot
tell a board piece from the UI chrome drawn over the same canvas — which T-031
would fix for it, by giving the board real focusable nodes.
